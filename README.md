প্রাণিবিদ্যার শিক্ষার্থীদের জন্য একটি স্ট্যাটিক ওয়েবসাইট। কোনো বিল্ড ধাপ, সার্ভার বা ডেটাবেস প্রয়োজন নেই।

## GitHub Pages-এ প্রকাশ

১. GitHub-এ লগইন করে **New repository** নির্বাচন করুন। চাইলে নাম দিন `zoology`; রিপোজিটরি পাবলিক রাখুন।
২. **Add file → Upload files** থেকে এই রিপোজিটরির সব HTML ফাইল, `README.md` এবং `assets` ফোল্ডারের ফাইলগুলো আপলোড করে কমিট করুন। `index.html` অবশ্যই রিপোজিটরির মূল ফোল্ডারে থাকবে। বিদ্যমান রিপোজিটরি ব্যবহার করলে ফাইলগুলো তার মূল ফোল্ডারে রাখুন।
৩. মূল গুগল সাইটের প্রাণিবিদ্যার ছবিটি মালিকের সরবরাহ করা `hero.jpg` নামে `assets/hero.jpg` অবস্থানে আপলোড করুন। ছবি না থাকলে হোমে স্থানধারক দেখা যাবে।
৪. রিপোজিটরির **Settings → Pages** খুলুন। **Build and deployment**-এ **Deploy from a branch** নির্বাচন করুন। প্রকাশের শাখা (সাধারণত `main`) এবং `/ (root)` নির্বাচন করে **Save** চাপুন।
৫. কিছুক্ষণ পর একই Pages সেটিংসে প্রদর্শিত লিংক খুলে সব পৃষ্ঠা, ছবি ও লিংক পরীক্ষা করুন। সাধারণত ঠিকানা হবে `https://ব্যবহারকারীর-নাম.github.io/zoology/`। পরিবর্তন প্রকাশিত হতে কিছু সময় লাগতে পারে।

## তথ্য হালনাগাদ

- `notice-board.html`-এ নোটিশের প্রকাশের সঠিক তারিখ যোগ করুন। নতুন নোটিশ তালিকার শুরুতে রাখুন; প্রতিটিতে তারিখ দিন। সব `.notice-entry` সরালে খালি অবস্থার বার্তা দেখা যাবে (জাভাস্ক্রিপ্ট চালু থাকতে হবে)।
- `about.html`-এ ১৪টি কার্ডে প্রকৃত ছবি, নাম ও ভূমিকা যোগ করুন; ছবিও `assets/`-এ রাখুন।
- একাডেমিক তালিকার “বিস্তারিত দেখুন” মূল সাইটে লিংক হিসেবে পাওয়া যায়নি; সঠিক লিংক পাওয়া গেলে যোগ করুন। মৎস্যবিদ্যার তালিকা মূল সাইটে কীটতত্ত্বের তালিকার সম্পূর্ণ অনুলিপি ছিল; তাই ভুল পুনরাবৃত্তির বদলে সঠিক তথ্যের স্থানধারক রাখা হয়েছে।
- তৃতীয় বর্ষের পরীক্ষার তারিখ এবং প্রকৃত লোগো পাওয়া গেলে যোগ করুন। এক্সাম কর্নারের পাহাড়-হ্রদের ছবিটি তৈরি করা চিত্র; মূল ছবিটি পাওয়া গেলে প্রতিস্থাপন করা যায়।
- দৃশ্যমান ফন্টের জন্য Google Fonts ব্যবহৃত হয়েছে; ইন্টারনেট না থাকলে ব্রাউজারের সেরিফ ফন্ট দেখা যাবে।
