# Zoology - প্রাণিবিদ্যা

Zoology - প্রাণিবিদ্যা গ্রুপের ওয়েবসাইট — GitHub Pages সংস্করণ।

**লাইভ সাইট:** https://sikdershakib.github.io/Zoology31/

## পেজগুলো

- `index.html` — হোম (নোটিশ বক্স + যোগাযোগ)
- `academic-post.html` — অনার্স ১ম–৪র্থ বর্ষের বিষয় কোড
- `exam-corner.html` — পরীক্ষার রুটিন ও সাজেশন
- `notice-board.html` — নোটিশ বোর্ড
- `about.html` — আমাদের সম্পর্কে (টিম কার্ড)

## কীভাবে চালু করবেন (GitHub Pages)

1. রিপোর **Settings → Pages**-এ যান
2. **Build and deployment → Source:** "Deploy from a branch"
3. **Branch:** `main`, ফোল্ডার `/ (root)` → **Save**
4. কয়েক মিনিট পর সাইট লাইভ হবে: https://sikdershakib.github.io/Zoology31/

## ফাইল গঠন

```
index.html
academic-post.html
exam-corner.html
notice-board.html
about.html
assets/
  css/style.css      — সব স্টাইল (Noto Serif Bengali)
  js/main.js         — মোবাইল মেনু + গ্রুপ খোলা/বন্ধ
  hero.jpg           — হোমের ব্যানার ছবি (যোগ করতে হবে)
```

## যা এখনো যোগ করতে হবে

- `assets/hero.jpg` — হোমের বড় ব্যানার ছবি
- এক্সাম কর্নারের ডাউনলোড/লিংকগুলোর আসল ঠিকানা
- About পেজের টিম সদস্যদের আসল নাম, পদবি ও ছবি
- নতুন নোটিশ এলে `notice-board.html`-এ যোগ করো

সব লেখা বাংলায়, ফন্ট Noto Serif Bengali।
